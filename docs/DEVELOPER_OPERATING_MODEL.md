# CIAOMIND 产业协同开发部

组织与工作台设计 v1，2026-11-19。沿用[产品与协作指针](PRODUCT_DIRECTION.md)和[平台建设蓝图](PLATFORM_BLUEPRINT.md)。

## 部门负责什么

产业协同开发部把文化、设计、制造、渠道和资金组织成可交付的项目，并把验证过的方法沉淀成可复用的标准、模板、工具和合作网络。内部团队维护规则、平台和交付质量。外部开发者通过自己的组织或个人身份参与指定项目，独立管理贡献和责任。

每个项目指定一位项目开发负责人，负责从立项到收尾，明确交付物、下一棒负责人、确认人和证据。部门负责人决定项目优先级、资源和授权范围。合同、付款与重大承诺由公司授权人员按各自职责处理。

## 项目角色和分工

同一人可以兼任多个角色。项目开始时记录每人的职责、交付标准和签收对象，外部参与方同时登记业务能力和实际能访问的项目。

| 角色 | 交付什么 | 谁确认 |
| --- | --- | --- |
| 项目开发负责人 | 需求、范围、预算、里程碑、伙伴和风险，推动每次交接 | 部门负责人确认立项和资源。交付由约定的接收方签收 |
| 文化资产与 IP 开发者 | 资料档案、来源、权利主体、用途、地区、期限、署名、保护约束和授权证据 | 实际权利方或有权代表确认授权。文化机构按项目安排确认表达与保护要求 |
| 数字化与设计开发者 | 采集记录、结构化元数据、数字原件、衍生设计版本、样品简报 | 文化负责人核对来源和表达。制造方确认规格能读懂、能估价 |
| 工艺与制造开发者 | 材料和工艺规格、打样计划、最小起订量、报价、交期、质检与返工记录 | 制造方确认可生产性。委托方确认样品或交付 |
| 品牌与市场开发者 | 受众、定价建议、品牌叙事、销售内容、渠道上架和反馈记录 | 品牌方确认表达和渠道。涉及文化素材的商业用途走权利方确认 |
| 产业生态与伙伴开发者 | 机构和供应商的能力档案，核验地区、工艺、产能与交付条件，撮合并推动合作 | 项目负责人确认伙伴和任务。伙伴确认参与范围和承诺 |
| 经营与财务开发者 | 订单、实收、成本、回款、分配及保护再投入记录，计算单项目经营结果 | 财务确认口径和凭证。授权人员审批付款、收益分配和对外经营数据 |
| 平台与集成开发者 | 工作台、AI、API、文化数据及设备连接器、数据权限和运维 | 模块维护人复核版本。业务角色验收实际操作和输出 |
| 质量与发布负责人 | 将授权、实物质量、权限、版本和修复记录汇成发布证据 | 权利、制造、财务各确认自己的事项。发布负责人汇总并批准上线范围 |

资本合作方可在授权范围查看项目经营报告、核对尽调材料并表达合作意向。由经营与财务开发者整理证据，项目负责人推进沟通，授权人员决定融资条款。循环工作由文化机构、制造和运营共同提出保护、维修、再制造方案，财务按协议核对实际回投凭证。

## 一个工作台怎么分权限

- 每个账号先选择组织和项目，再按职责看到可做的操作。内部沿用现有的 owner、manager、contributor、viewer 基础权限，业务角色用于指明职责、任务和签收人。
- 在邀请外部机构前，验证资料级访问和跨组织隔离。外部制造方可接收本次打样所需规格、提交报价和样品。权利方可处理授权与相关审核。市场方可读取已获准对外使用的素材。财务和资本方只在被授予的范围查看相应凭证或报告。
- 个人角色、应用权限和素材授权分别核对。交接记录包含交付物版本、证据、提交人、签收人和状态。改用途或超范围须重新确认。项目结束可撤销权限，保留按项目规则需要的审计记录。
- Muse 或其他 AI 助手可整理材料、推荐下一位负责人、拟写简报和提醒。授权、签约、付款、对外发布由有相应权限的人确认。

## 官网入口和运营流程

沿用现有角色入口和 Business OS。官网的「开发者与共建」提供三个入口：**发起项目、提供能力、接入系统**。合作方日常在「我的项目」里只需要看负责的事、所需材料、要交的结果和确认状态。团队工作台处理分派、审核、交接、反馈和经营记录。接口文档、测试空间、我的应用、版本及支持工单归入开发者后台。

现有六类伙伴入口继续按来访者身份组织。文化机构走权利与资料，品牌和设计方走设计与市场，工匠和制造商走打样与履约，运营方走订单与反馈，产业机构走伙伴撮合，资本方走项目评估与资料核验。进入项目后再分配部门职责。软件、数据或设备团队从「接入系统」登记应用或连接器。

申请流程为提交能力或应用用途 → 核验组织与责任人 → 授予项目或测试权限 → 提交首个交付与证据 → 业务验收和发布审核 → 维护、升级或撤销。官网按钮随实际可用能力开放。公开角色简报和当前业务后台的能力以实际测试为准。

## 首个项目用陶瓷素材走通

先用模拟素材走一遍。进入实际项目后，由愿意参与的文化机构选一项能授权的陶瓷素材，先确定数字展示、设计衍生和后续商品化分别允许到什么范围。设计师将许可写进生产简报，制造方回传与该版本对应的样品方案、报价和交期。运营方有明确授权后才能制作对外内容。实际发生交易后，财务核对实收、成本和分配，按约定记录保护投入。

首轮明确项目与伙伴、权利与内容、平台与交付三项日常责任，小团队可以兼任。实际权利方、制造方和财务人员各签收自己负责的记录。项目负责人用三个结果判断能否复制：交接等待时间、因遗漏权利或规格而产生的返工次数，以及哪些步骤有证据可以写成模板。未完成的案例保留为待验证。
