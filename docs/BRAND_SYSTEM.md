# CIAOMIND 标识与传播规范

版本为 2026-11-19。网站标识呈现参考惠灵顿（中国）教育集团的徽记与分层字标组合，具体观察和应用决策见 [DESIGN.md](../DESIGN.md)。

## 网站呈现修正（2026-11-19）

依据用户最新要求：开场演示保留横向 CIAOMIND，说明行置于星形和完整字标整组下方，左右边界与整组标识对齐。进入页面后，页眉和页脚恢复 CIAO 在上、MIND 在下的紧凑叠排，不显示说明行。网站两种呈现共用原有轮廓与配色；下载素材中的商务横版继续保留。

## 统一组合

主标识由现有四角星图形、CIAOMIND 完整名称和 CULTURE · INDUSTRY · INNOVATION 说明行组成。说明行是本次依据产品愿景确定的传播用语。

- 横版用于开场演示、邮件和一般商务传播；网站页眉、页脚使用上述叠排版。
- 居中版用于封面、正式文件和空间较充足的画面。
- 图标版用于头像、浏览器图标和小尺寸应用。
- 浅色背景使用深绿版，深绿背景使用反白版，单色印刷使用黑色版。
- 图形和文字按原始比例缩放，四周至少保留四分之一个图标宽度的留白。

## 使用入口

官网 /zh/brand/ 提供八语资源页。完整素材包在 /brand/ciaomind-brand-kit.zip，格式清单在 /brand/brand-manifest.json。

| 媒介 | 资源 | 本轮交付 |
| --- | --- | --- |
| 官网 | 顶部、页脚、开场、分享图与组织标识 | 共用组件、轮廓和配色 |
| 社交媒体 | 头像、图文、竖版与宽幅封面 | PNG 与 SVG 模板 |
| 演示 | 16:9 封面 | 可导入演示软件的 PNG 与 SVG |
| 视频 | 16:9 片尾 | PNG 与 SVG 画面 |
| 邮件 | 公司署名 | HTML 模板 |
| 正式文件 | A4 信笺 | 可编辑 HTML 与 PDF |

社交平台实际头像及封面的发布、既有演示与历史文件的替换，按具体账号和文件核对后记录。宽幅素材以各平台当前裁切结果为准。

## 持续制作

所有后续制作从 lib/brand-paths.ts、lib/brand-signature.json 和 scripts/build-brand-assets.py 生成或引用。文件中的企业名称、网址与联络方式按公司现行公开资料维护。

新内容提交时核对标识组合、色彩、留白、尺寸、可读性及实际使用场景。平台发布记录和历史文件更新情况纳入 GitHub 与 Muse 协作任务。

网站角色、项目和业务流程继续遵循 [产品指针](PRODUCT_DIRECTION.md)。
