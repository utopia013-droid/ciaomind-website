## 目标

从 IP、世界文化遗产与文化要素的保护出发，深度结合 AI 和物联网技术推进数字化，连接设计、工艺、精益制造、品牌营销、市场与财务管理，推动分散运营方之间的产业协同重组。

让区域文化、区域品牌、区域供应链和区域产业要素连接更广阔的市场。通过可验证的经营数据和可复制的协作体系，为规模化发展和资本合作创造条件。以循环发展为价值观，使经营成果持续支持保护、传承和新的创造。

## 价值链与产品任务

| 环节 | 用户要完成的事 | 产品需要支持的信息与交接 |
| --- | --- | --- |
| 保护与数字化 | 说明资源、持有者、来源及使用目的 | 权利范围、授权、利益分配、数字档案、版本、来源与责任人 |
| AI 与物联网 | 找到适合项目的数据和辅助能力 | 采集范围、资料整理、识别与设计辅助、环境及设备状态、溯源、数据权限和人工复核 |
| 设计与精益制造 | 把文化表达转成可交付的产品或服务 | 设计简报、材料、样品、规格、质量要求、成本、交期与变更确认 |
| 品牌与市场 | 明确客户、表达和销售路径 | 品牌定位、区域故事、多语言内容、渠道、市场反馈和服务责任 |
| 运营与财务 | 让不同参与方围绕同一项目协同 | 任务、负责人、依赖、里程碑、交付物、订单、成本、收入、现金流和确认记录 |
| 扩张与资本合作 | 判断模式能否重复和获得支持 | 单项目经济性、可核查合同与权利、履约记录、管理报告、资金用途和项目评估 |
| 循环与再投入 | 让资源和产品价值持续发挥作用 | 保存、修复、维修、再制造、再销售、授权收益及文化保护投入的记录 |

AI 与物联网贯穿业务链，具体采用方式由数据、权限、项目需要和可验证效果决定。

## 四项迭代判断

每个内容修改、页面调整和功能任务写清以下问题的答案。

- 用户理解更容易了吗。目标用户能说明服务对象、解决的问题、合作方式和当前能力。
- 用户操作更方便了吗。入口明确，下一步可执行，表单保留必要上下文，错误和等待状态可恢复。
- 用户协同更顺畅了吗。参与方能看到自己负责的任务、可访问的资料、交付要求、确认人和进度。
- 产业要素连接更有效了吗。文化资源、设计、制造、品牌、渠道与资金需求之间形成可验证的匹配与交接。

## 信息结构

首页先呈现欧洲企业设立，再呈现文化与产业协同。企业设立服务连接欧洲市场进入、组织准备和专业执行支持。

服务页按用户目标解释路径。文化业务沿价值链展开，使用案例和明确的项目入口帮助用户理解。视频页将外部参考案例按业务环节组织，显示发布方与来源，并连接对应的咨询主题。

文化机构与权利持有者、区域品牌与设计师、工匠与制造商、市场运营方、区域产业组织和资本合作方各有清晰入口。按具体角色提供信息、任务和授权范围。

客户、团队及合作方的工作空间围绕真实业务进度建立。实际权限和功能状态应与页面呈现一致。

## 共同推进方式

GitHub 保存产品指针、代码、任务、PR 和验收证据。Muse 通过既有调度台协调任务、确认输入版本、跟踪阻塞并汇总结果。实现者提交变更与检查记录，复核者核对用户路径和实际交付。

每项迭代记录目标用户、观察到的阻塞、所属环节、最小改进、责任方、交付位置、验收方式、实际结果和下一步。任务领取、提交、接收、审核和发布各有自己的证据。

用户已经授权的常规操作按当前会话范围继续推进。预算、权限、敏感资料和对外承诺沿用用户实际授权边界。

公开咨询由访客通过自己的邮箱发送预填主题的邮件草稿。AI 与物联网接入、资本合作及产业重组按具体项目评估。后续任务以实测状态更新这一节。

### 首轮实现与后续验收

首页、服务页和愿景页从六个业务环节和六类参与者进入项目简报。行业视频沿用所选环节。简报带入角色或环节，访客可调整选择，填写资源、合作目标和下一步负责人，复制给伙伴或交由自己的邮箱发送。欧洲设立继续使用独立咨询路径。公开简报在访客浏览器中编辑，项目建档、认领、审批及业务入账须在实际执行系统中另行确认。

后续按同一条任务记录实际交接：权利持有人确认来源及许可；制造方确认材料、样品与交付；品牌和运营方核对渠道、订单与反馈；财务负责方统一项目成本、收入、现金流和分配口径。先以可复核的单项目结果评估复制扩张及资本合作，再对照协议与支付凭证核验有多少经营收益实际回到保护、维修或传承。每轮用一个真实阻塞和一份可复核的用户路径结果更新网站议题及 Muse 交接。

## 优先推进

- P0 将角色、目标、可提供的资源、所需帮助与可执行的下一步连成一条清晰的用户路径。
- P1 把需求、责任方、权限、交付物、里程碑、确认和反馈连接为项目协作流程。
- P1 建立有来源和核验状态的区域资源与伙伴能力目录，围绕真实需求推进匹配。
- P2 选择具体项目验证 AI 与物联网连接、交付质量、单项目经济性和可复制运营。

每轮根据已观察到的阻塞和反馈调整顺序。指标包括找到合适入口的成功率、完成需求说明的情况、交接等待时间、返工、交付结果和可核查的项目经济性。初始基线由实测建立。

## 每次交付的检查

- 页面表达与本指针对齐，且能对应明确用户和业务环节。
- 手机和桌面端能找到入口、完成关键操作并理解当前状态。
- 八种语言的必要标签、内容、链接与错误反馈可用。
- 合作、咨询、订单与数据处理的实际行为和文字一致。
- 涉及协同的修改验证权限、责任、交接及恢复路径。
- 记录实际检查、分支、提交、公开链接和待解决问题。
